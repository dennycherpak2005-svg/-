🔗 n8n Cold-Mail-Versand

So funktioniert's: Mein Tool schickt pro Lead ein JSON an deinen Webhook. Deine n8n-Automation übernimmt das Versenden.
Gesendete Felder pro Lead:
{
  "name": "...", "email": "...", "phone": "...",
  "company": "...", "position": "...", "website": "...",
  "location": "...", "source": "...", "temperature": "...", "status": "..."
}
💡 Tipp: Im n8n-Webhook-Node unter „Allowed Origins (CORS)" ein * eintragen – dann bekommt mein Tool eine Erfolgs-Bestätigung. Ohne das wird trotzdem gesendet (nur ohne Rückmeldung).
